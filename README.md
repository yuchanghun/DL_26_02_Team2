# DL_26_02_Team2 · 딥러닝 응용 팀 프로젝트 (2026-2, T02)

> 2026-11-17: 35개 단어 분류에서 명령어 10개 + "명령 아님"(11개 클래스)으로 바꾸기로 함. 기준선 A는 whisper-base 인코더로 정함. 자세한 내용은 [설계결정_11클래스.md](설계결정_11클래스.md). 아래 01~04는 35개 단어로 해 본 탐색 결과.

손을 쓰기 어려운 상황을 위한 짧은 음성 명령어 인식: 사전 학습 Whisper 인코더(기준선 A)와 직접 만든 스펙트로그램 CNN(팀 모델 B) 비교, 명령이 아닌 소리 걸러 내기 포함

- 데이터: Google Speech Commands v0.02 (CC BY 4.0), 35개 단어, 105,829개 녹음. 노트북이 torchaudio로 내려받는다
- 환경: Colab T4 GPU, PyTorch + torchaudio (로컬은 conda 환경 `team`: torch 2.11, torchaudio 2.11)
- 기간: 2026-11-16 ~ 2026-12-07
