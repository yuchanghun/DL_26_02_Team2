팀 번호 T02 | 유형 자유 | 제목 손을 쓰기 어려운 상황을 위한 짧은 음성 명령어 인식: 사전 학습 wav2vec2와 직접 만든 스펙트로그램 CNN 비교

1. 문제: 요리·운전 중이거나 손이 불편한 사람이 짧은 음성 명령으로 기기를 조작. 같은 단어도 화자·속도·잡음에 따라 파형이 크게 달라 규칙으로 정의할 수 없다.
입력 → 출력: 1초 음성(16kHz) → 35개 영어 명령어 중 하나(yes, no, up, down, stop, go, 숫자 0~9 등)
2. 데이터 출처: Google Speech Commands v0.02 (Warden, 2018), download.tensorflow.org/data/speech_commands_v0.02.tar.gz, CC BY 4.0
크기: 녹음 105,829개, 단어별 1,557(forward)~4,052개(five)로 2.6배 차이. 배경 잡음 6개. 9.9%가 1초 미만이라 1초로 맞춤(01 노트북).
분할: 공식 목록 그대로: 학습 84,843 / 검증 9,981 / 시험 11,005. 화자 기준 분할이라 학습·시험 화자 겹침 0명(직접 확인). 설정은 검증으로만 고르고 시험은 마지막에 한 번만 쓴다.
예시 2개: 01 노트북 셀 5 그림 (figs/01_예시_yes_three.png)
3. 기준선 A: torchaudio WAV2VEC2_BASE(영어 음성 960시간으로 사전 학습, 94,370,944개)를 고정하고 마지막 12층 출력의 시간 평균(768차원) 위에 Linear(768 → 35, 26,915개)만 학습.
A 결과: 검증 정확도 90.19%, 매크로 F1 0.8937(02 노트북 E02, T4). 층별로는 5층이 95.41%로 가장 높고 12층이 가장 낮았다(E03).
4. 팀 모델 B: 로그 멜 스펙트로그램(1 × 64 × 101) → [합성곱 3×3 + 배치 정규화 + ReLU + 최대 풀링] × 4(채널 16 → 32 → 64 → 128) → 전역 평균 풀링 → Linear(128 → 35). 약 10만 개로 A의 1% 이하. A와 달리 사전 학습 없이 우리 데이터로만 배우고 소리를 그림으로 바꿔 합성곱으로 처리. 교재 4장 CNN 분류기를 소리 그림에 적용(A는 7장 트랜스포머 계열).
5. 지표: 정확도와 매크로 F1(단어별 녹음 수가 2.6배 달라 적은 단어의 성능도 보려고).
목표와 0번 기준: 0번 기준(가장 많은 단어 zero만): 검증 정확도 3.85%, 매크로 F1 0.0021(01 노트북). 목표: B 검증 정확도 95% 이상(A 최고 층 E03 95.41%에 맞먹게). B 첫 학습은 91.62%(E04).
6. 학습 시간: A: 특징 뽑기 140초(T4, 한 번 저장) + Linear 5.8초. B: 스펙트로그램 33초(한 번) + 에폭당 8.0초, 20에폭 166초(03 노트북). 실험 13회: 0번·비딥러닝(MFCC) 기준, A, B, 층별, 데이터 수 3, 증강, 멜 밴드 3, 잡음, 양자화.
7. 다른 과목과 겹침: [확인 필요] 다른 과목 프로젝트와 겹치지 않음

비교 실험 후보
1. 학습 데이터 10 / 30 / 100% (A, B) → B는 사전 학습이 없어 데이터가 줄수록 A와 차이가 벌어질 것이다.
2. 시험에 잡음 섞기 SNR 20 / 10 / 0 dB → 단어 무늬가 잡음에 묻히는 0 dB(01 노트북 셀 7)에서 크게 떨어질 것이다.
3. B에 SpecAugment(일부 구간 가리기) 유무 → 녹음이 잘리거나 잡음이 섞인 경우에 강해져 검증 정확도가 오를 것이다.

위험과 대안
- Colab GPU가 잡히지 않는다 → SMOKE 설정으로 코드를 먼저 완성하고 Kaggle Notebooks로 옮긴다.
- 매번 2.4GB를 받고 특징을 다시 뽑느라 시간이 부족하다 → Google Drive에 데이터와 뽑은 특징을 저장해 다시 쓴다.
- 35개 단어 학습이 1회 30분을 넘는다 → 이 데이터의 표준 축소 과제인 10개 명령어로 줄인다.
